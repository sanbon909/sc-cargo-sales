# Changelog

## 1.0.1 (2026-11-16)

- Renamed the app to **Sanbon's SC Tools** (the download is now `Sanbons-SC-Tools-win64.zip` and the app is `Sanbons SC Tools.exe`).
- New **Blueprints** tab: search a crafting blueprint to see its parts, materials and amounts, and how to unlock it. Data comes from the Star Citizen Wiki API.
- **Material quality** sliders (0 to 1000) for each material, plus an "All materials" slider and a Reset button. **Item stats** shows how each stat changes compared with quality 500 materials.

## 1.0.0 (2026-11-14)

- First release: the **Cargo** tab. Search a commodity to see every terminal where you can sell or buy it, with location, system, demand, SCU box sizes and the latest reported price, using data from UEX.
